# 锡院助手 · Windows 前端设计文档

> 版本 v1.0 · 2026-09-17 · 基于对官方融合门户（my.cwxu.edu.cn）与慧新E校（10.3.100.110）的实机走查
> 走查环境：真实账号登录门户全部页面 + SSO 桥进慧新E校（截图与 DOM 快照取证）

## 一、设计定位

**一句话**：把「信息墙式的政务门户」重做成「以今天为中心的个人校园工作台」。

- **单页面职责**：打开应用 3 秒内看到「现在最该知道的事」——今天有什么课、临近什么会、一卡通还剩多少钱、有没有新待办/公告。
- **桌面优先**：这是常驻 Windows 的客户端（托盘 + 系统通知），不是网页复刻；用原生感交互（命令面板、全局快捷键、深浅主题跟随系统）建立与网页版的体验差。
- **不做官方站内的深度流程**（选课、报销等仍在官方系统完成，客户端只做「看 + 提醒 + 直达」）。

## 三、功能重设计映射（官方功能 → 锡院助手）

原则：**官方有的做减法或直达，官方缺的做加法**；凡属「看一眼」的信息进卡片流，凡属「办一件事」的流程一律外链官方系统。

### 3.1 头像上传（用户点名案例，P0）

官方：裸文件框 + 三行红字要求。锡院助手：**上传即服务的三步弹层**。

1. 选图（或拖拽到弹层）→ 2. **1:1 裁切器**（圆形/方形预览，滚轮缩放拖动取景，默认方形框锁定 1:1）→ 3. **压缩导出**：Canvas 重采样至 ≤512×512，JPEG 质量 0.85 起步自动降质二分逼近 ≤200KB（默认 jpg；源图为 png 且 ≤200KB 时保留 png 选项），实时显示「原 2.4MB → 183KB」→ 上传。
- 实现选型见 §7（react-easy-crop + Canvas API，零新依赖负担）。
- 顺带解决：裁切结果同时用于客户端本地头像展示（不再依赖官方服务端清晰度）。

## 六、视觉方向（Token 系统初稿）

**性格**：安静的专业工具，紫是品牌而非背景。不做政务大顶栏，不做仪表盘 SaaS 模板脸。

### 色彩（浅主题为默认）

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#5B2E90` 锡院紫（校徽紫降饱和） | 品牌、主按钮、选中态 |
| `--bg` | `#F7F6F9` 纸灰 | 页面底 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--text` | `#1F1B29` 墨紫黑 | 正文 |
| `--text-2` | `#6E6878` | 次要文字 |
| `--wallet` 域绿 | `#0F9D77` | 一卡通/余额 |
| `--info` 域紫 | `#7C5CBF` | 资讯/公告 |
| `--todo` 域琥珀 | `#D9822B` | 待办 |
| `--sched` 域湖蓝 | `#2B7DBF` | 日程/会议 |
| `--alert` | `#D9455B` | 低余额/告警 |

- 深主题：`#17151C` 底 + 同域色提亮一档；对比度全部 ≥ WCAG AA。
- **域色编码是签名系统**：导航图标、卡片角标、通知分类点、命令面板分组全部同源同色——「看颜色知道是哪类事」。

### 字体

- 正文/UI：`"Segoe UI", "Microsoft YaHei UI", system-ui`（Windows 原生，零加载成本）。
- 数字/金额显示：`"Outfit"`（Google Fonts，仅数字拉丁子集，woff2 ~15KB）+ `tabular-nums`，用于余额、时间、计数——「钱和时间是等宽数字」。
- 层级靠字号/字重/域色，不靠彩底横幅。

### 布局与签名

- 4px 基线栅格；卡片圆角 10px、1px 边线 + 极浅投影（阴影不做层级语言，边线和域色做）。
- **签名元素：域色 spine**——顶栏导航项左侧 3px 域色竖线（选中时点亮为圆点+下划线），与内容卡左上 8px 域色角标、通知分类点连成一条视觉线索。全应用唯一的大胆之处，其余全部克制。
- 动效：仅两处——页面切换 120ms 淡入、数字变化（余额刷新）300ms 滚动；尊重 `prefers-reduced-motion`。

### 自评（防模板化检查）

- 不属于 AI 默认三型（奶油+赤陶 / 纯黑+酸绿 / 报刊细线），品牌紫锚定学校 VI、域色系统来自内容语义而非装饰。
- 「域色 spine」是本 brief 特有：它编码的是「校园事务的域」（钱/事/讯/程），是信息不是装饰。
- 风险点：紫在深主题易闷——深主题 brand 提亮至 `#8B5CF6` 档并降低使用面积。

## 七、组件库与技术选型（GitHub 实测数据，2026-09-17）

### 结论先行

**方案 A（采用）：Tailwind CSS v4 + shadcn/ui + lucide-react**。组件源码拷贝进仓库、样式全自研——与「政务后台」视觉彻底脱钩；Radix 无头内核保证键盘/焦点/a11y；官方支持 React 19。备选 B：Radix primitives 裸用自研皮肤（自由度最高、最慢）。**明确规避 Ant Design / Arco / Semi**——它们正是「政务后台脸」的来源（AntD 还需要 React 19 官方补丁包 `@ant-design/v5-patch-for-react-19`）。

### 关键候选对比

| 库 | repo | star | 判定 |
|---|---|---|---|
| shadcn/ui | shadcn-ui/ui | 124k（日更） | **采用**（源码入库） |
| Radix primitives | radix-ui/primitives | 19k（WorkOS 维护） | 作为 shadcn 内核随行 |
| Mantine | mantinedev/mantine | 32k | 备选（CSS Modules 与 Tailwind 双轨摩擦） |
| HeroUI（原 NextUI） | heroui-inc/heroui | 31k | 备选（视觉偏圆润移动端） |
| Ant Design 5 | ant-design/ant-design | 100k | 排除 |
| Semi / Arco | DouyinFE / arco-design | 10k / 5.7k | 排除 |

### 头像上传三件套（对应 §3.1）

- **裁切：react-easy-crop**（ValentinH/react-easy-crop，2.8k，2026-09 活跃）——`cropShape="round"` 原生圆形预览、缩放拖拽齐全。react-image-crop（4.1k）更底层、圆形预览要自绘；react-avatar-editor 无优势。
- **压缩：浏览器 Canvas API**（drawImage 降采样 + `toBlob('image/jpeg', q)` 二分逼近 200KB），零依赖；wasm 方案（squoosh，其 `@squoosh/lib` 已被官方弃用）收益为零，不采用。
- 总新增依赖：**1 个包**。

### 图标与空态

- 图标主选 **lucide-react**（24.6k，shadcn 默认生态、tree-shake 友好）；iconify 作特殊图标兜底；phosphor 维护放缓不用。
- 空态插画用 **unDraw**（MIT，SVG 单色可一键替换品牌紫）+ lucide 色块自绘；不用大图占位（对齐痛点 #8）。

## 附录 A · 应用中心 30 应用 SSO 实测矩阵（2026-09-17，浏览器逐站访问）

官方 `isCas:"cas"` 元数据**不可全信**（有标记 cas 实则需单独登录的，也有域名仅 WebVPN 可达的）。客户端应用页应自带可达性元数据，打开策略分三类：**A=CAS 直达**（签发 ST 自动进内页）、**B=WebVPN 路径**（域名校内不可直连，需 WebVPN 会话，M4 自动包装）、**C=外链浏览器**。

### 对 M2/M4 的设计结论

1. **应用页打开策略引擎**：按附录 A 的 A/B/C 分类决定「CAS 直达 / WebVPN 包装 / 浏览器外链」，元数据集中配置（`appAccess.json`），不信任官方 isCas 字段。
2. **两大表单底座**（whall gemini、yd.cwxu.edu.cn 低代码）SSO 稳定且为标准 Web 表单——「直达」体验成立；客户端只做打开+会话保持，不做表单重写。
3. **门户数据接口全景已采集**（M2 直接复用）：`/api/upp/appStore/v2/queryApp`（应用清单）、`/api/upp/layout/getPageContent`（首页布局）、`/api/uppinfo/infoCenter/querySimpleInfoCenter`（资讯栏目）、`/api/uppflow/process/querySimpleFlowItems`（待办三区）、`/api/uppcard/kbsz/queryAWeekSchedule`（课表）、`/api/uppexcard/ext/dynamicData/...`（会议卡片，源 10.1.90.34）、`/api/uppexcard/ext/myData/getData`（邮箱未读）、`/api/uppmessage/message/queryUserMessagePage`（消息中心）、`/api/upp/config/querySemesterInfo`（学期）。
