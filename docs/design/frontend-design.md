# 锡院助手 · Windows 前端设计文档

> 版本 v1.0 · 2026-09-17 · 基于对官方融合门户（my.cwxu.edu.cn）与慧新E校（10.3.100.110）的实机走查
> 走查环境：真实账号登录门户全部页面 + SSO 桥进慧新E校（截图与 DOM 快照取证）

## 一、设计定位

**一句话**：把「信息墙式的政务门户」重做成「以今天为中心的个人校园工作台」。

- **单页面职责**：打开应用 3 秒内看到「现在最该知道的事」——今天有什么课、临近什么会、一卡通还剩多少钱、有没有新待办/公告。
- **桌面优先**：这是常驻 Windows 的客户端（托盘 + 系统通知），不是网页复刻；用原生感交互（命令面板、全局快捷键、深浅主题跟随系统）建立与网页版的体验差。
- **不做官方站内的深度流程**（选课、报销等仍在官方系统完成，客户端只做「看 + 提醒 + 直达」）。

## 三、功能重设计映射（官方功能 → 锡院助手）

原则：**官方有的做减法或直达，官方缺的做加法**；凡属「看一眼」的信息进卡片流，凡属「办一件事」的流程一律外链官方系统。

### 3.1 头像上传（用户点名案例，P0）

官方：裸文件框 + 三行红字要求。锡院助手：**上传即服务的三步弹层**。

1. 选图（或拖拽到弹层）→ 2. **1:1 裁切器**（圆形/方形预览，滚轮缩放拖动取景，默认方形框锁定 1:1）→ 3. **压缩导出**：Canvas 重采样至 ≤512×512，JPEG 质量 0.85 起步自动降质二分逼近 ≤200KB（默认 jpg；源图为 png 且 ≤200KB 时保留 png 选项），实时显示「原 2.4MB → 183KB」→ 上传。
- 实现选型见 §7（react-easy-crop + Canvas API，零新依赖负担）。
- 顺带解决：裁切结果同时用于客户端本地头像展示（不再依赖官方服务端清晰度）。

### 首页「今日」线框（v2 定稿 · 用户拍板精简版）

> **用户决策（2026-09-17）**：首页去掉资讯中心、快捷应用、待办中心、会议、信息服务、课表卡片六个模块——首页只做「当下最重要的三件事」。资讯/待办/会议/应用均为独立页面（导航不变），靠 M5 系统通知推送到人，不靠首页堆叠。

- 被移除模块的去向：资讯→「资讯」页+M5 通知；待办→「待办」页+M5 通知；会议→「日程」页+M5 通知；信息服务→「应用」页服务分组；课表→独立「课表」页（§5.1）；首页快捷入口→固定 4-6 个动作按钮（查电费/充值/报修/办事大厅/全部应用），不是官方那种可排序应用堆叠。
- 「下一节课」横幅依赖课表导入（§5.1）；无课表数据时整行隐藏，不占位。
- 余额低于阈值时钱包卡自动转 `--alert` 色并触发系统通知（M5）。


功能规格（按用户需求逐条落实）：

1. **教务自动导入**：登录态复用 CAS 会话 → SSO 进正方教务 → `POST /jwglxt/kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151`（`xnm=<学年>&xqm=<学期代码：3=第1学期/12=第2/16=暑期>`，2026-09-17 实测通过）→ 解析 `kbList`（课程名/教室/教学班/节次 jc/周次位掩码 oldzc/考核方式）与 `xsxx`（学年学期）。教师身份课表接口同源，导入时按账号角色自动选端点（学生 `xskbcx_cxXsKb` 已验证；教师端点 M2.5 侦察）。
2. **导入/手动源隔离**：每门课带 `source: 'import' | 'manual'` 标签（用户口中「用户不可见标签」= 界面上以【导】角标呈现来源、但不打扰视觉）；**一切自动更新/调课解析只作用于 `source='import'` 的课程**，手动添加的课程永不触碰。
3. **自动对比更新**：每次导入新快照后与本地 diff（匹配键 `课程名+教学班 jxb_id`）：周次掩码/教室/节次有变化 → 仅更新匹配的导入课程并生成变更日志（「信息安全 教室 D4-207 → D4-305」）；新出现课程自动加入（source=import），消失课程标记「已停开」。
4. **调课通知自动调整**（override 模型，shiguangschedule 没有的部分，自建）：
   - 数据源：M5 公告流命中关键词（调课/调休/停课/补课/考试安排）的教务处/学院通知。
   - 两级解析：**L1 规则层**（正则+词表提取：课程名、原周次/星期/节次、新日期/新节次/新教室、生效范围）；**L2 置信分级**——要素齐全且课程名精确匹配已导入课程 → 高置信，自动应用并标记 `override.source=notice:<id>`；缺要素或匹配多门 → 低置信，进「待确认」列表由用户一键采纳/忽略。
   - 应用语义：override 叠加于导入课程之上（原数据保留可回滚）；通知撤回/修订 → 按通知 id 撤销对应 override。
5. **算法与数据模型移植**（来自 shiguangschedule，Apache-2.0）：`weeks: number[]` 显式周次列表（取代单双周标志位）、开学日↔周次互算（支持自定义周起始日）、重叠课程分列算法、默认节次表常量。渲染用 React absolute 定位重写（其 Compose 渲染不可复用）。
6. 作息时间表支持自定义（本校节次时间内置默认，可编辑）；支持手动添加课程（颜色自选、周期可跨周）；ICS 导出沿用 shiguangschedule 的展开式 VEVENT 方案。

## 六、视觉方向（Token 系统初稿）

**性格**：安静的专业工具，紫是品牌而非背景。不做政务大顶栏，不做仪表盘 SaaS 模板脸。

### 色彩（浅主题为默认）

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#5B2E90` 锡院紫（校徽紫降饱和） | 品牌、主按钮、选中态 |
| `--bg` | `#F7F6F9` 纸灰 | 页面底 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--text` | `#1F1B29` 墨紫黑 | 正文 |
| `--text-2` | `#6E6878` | 次要文字 |
| `--wallet` 域绿 | `#0F9D77` | 一卡通/余额 |
| `--info` 域紫 | `#7C5CBF` | 资讯/公告 |
| `--todo` 域琥珀 | `#D9822B` | 待办 |
| `--sched` 域湖蓝 | `#2B7DBF` | 日程/会议 |
| `--alert` | `#D9455B` | 低余额/告警 |

- 深主题：`#17151C` 底 + 同域色提亮一档；对比度全部 ≥ WCAG AA。
- **域色编码是签名系统**：导航图标、卡片角标、通知分类点、命令面板分组全部同源同色——「看颜色知道是哪类事」。

### 字体

- 正文/UI：`"Segoe UI", "Microsoft YaHei UI", system-ui`（Windows 原生，零加载成本）。
- 数字/金额显示：`"Outfit"`（Google Fonts，仅数字拉丁子集，woff2 ~15KB）+ `tabular-nums`，用于余额、时间、计数——「钱和时间是等宽数字」。
- 层级靠字号/字重/域色，不靠彩底横幅。

### 布局与签名

- 4px 基线栅格；卡片圆角 10px、1px 边线 + 极浅投影（阴影不做层级语言，边线和域色做）。
- **签名元素：域色 spine**——顶栏导航项左侧 3px 域色竖线（选中时点亮为圆点+下划线），与内容卡左上 8px 域色角标、通知分类点连成一条视觉线索。全应用唯一的大胆之处，其余全部克制。
- 动效：仅两处——页面切换 120ms 淡入、数字变化（余额刷新）300ms 滚动；尊重 `prefers-reduced-motion`。

### 自评（防模板化检查）

- 不属于 AI 默认三型（奶油+赤陶 / 纯黑+酸绿 / 报刊细线），品牌紫锚定学校 VI、域色系统来自内容语义而非装饰。
- 「域色 spine」是本 brief 特有：它编码的是「校园事务的域」（钱/事/讯/程），是信息不是装饰。
- 风险点：紫在深主题易闷——深主题 brand 提亮至 `#8B5CF6` 档并降低使用面积。
