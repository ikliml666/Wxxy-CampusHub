## 1. 已实测事实（不必重测，可直接引用）

### 1.1 教务 SSO 链路（2026-09-18 实测，代码见 `crates/campus-auth/src/jwglxt.rs`）

- 教务在 CAS 注册的 service = `https://jwgl.cwxu.edu.cn/sso/lyiotlogin`（自引用回跳）
- **ST 与 service 绑定**：门户 ticket 直接拿去教务 = 404；必须用已有 TGT 换发教务 service 的 ST
- 换票：`POST {CAS_BASE}/v1/tickets/{tgt}`（form `service=<JWGL_SERVICE>`）→ **200 + 纯文本 `ST-…`**（非 JSON）
- 落地链（5 跳 302）：`/sso/lyiotlogin?ticket=ST` → `/jwglxt/ticketlogin?uid=…` → `/xtgl/login_slogin.html` → `/xtgl/index_initMenu.html?jsdm=xs`
- 教务会话 cookie：`route` + `JSESSIONID`（与门户 `customsid` 相互独立，同一 jar 并存）
- **CAS 不种任何登录 cookie** → 会话续期只能靠客户端保存的 TGT
- 现成函数：`CasClient::sso_ticket(tgt, service)`、`CasClient::jwglxt_sso(tgt)`

### 1.2 课表接口

- `POST https://jwgl.cwxu.edu.cn/jwglxt/kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151`
  （`gnmkdm` 在 **query**；body 仅 `xnm=<学年起始年>&xqm=<3=第1学期/12=第2学期/16=暑期>`）
- 最小头组：仅 `Content-Type: application/x-www-form-urlencoded;charset=UTF-8`；
  **但必须带 `X-Requested-With: XMLHttpRequest`**——未登录时它让服务端返回 `901`，不带则返回 200 登录页 HTML（无法区分）
- 实测：本学年返回 8 条 `kbList`，字段与 `zhengfang::parse_kb_response` 映射**完全一致**，无需改解析器
- 参数推导口径（已定）：`xnm` = 门户 `SemesterInfo.start_date` 前 4 位；`xqm` = `semester` 的 `"1"→3 / "2"→12`
  （**不要用 `grade` 字段**：它是入学年级，对老生 ≠ 学年起始年）
- 失败模式：教务域无会话 + XRW → **HTTP 901**（空 body）；其他错误 → 见实现方实测补充

### 1.3 节次口径（与今日页同源）

- 教务 `jcs` 是**小节**号（如 `"3-4"`），校本作息是 **5 大节 × 2 小节**（大节 = 100 分钟）
- 大节时间（实测）：大节1 08:0?-…、大节2 **10:10-11:50**、大节3 **13:45-15:25**、大节4 **15:35-17:15**、大节5 …
- 映射：大节号 = `ceil(起始小节 / 2)`（`3-4节` → 大节 2 ✓ 与实测吻合）
- ⚠️ `campus-schedule::default_time_slots()` 是上游 13 节默认表（下午 14:00 起），**与本校不符**，
  它被 golden 测试钉住，**M2.5 不得修改它**；课表页一律走校本大节表
- 校本大节表现在是 `campus-portal::parse` 的**私有** `block_time_slots()`（`parse.rs:166`）。

## 2. 冻结契约

### 2.1 数据模型变更（`campus-schedule::model`）

| 变更 | 说明 |
|---|---|
| `Course` 新增 `#[serde(default)] pub disabled: bool` | 「已停开」标记（自动更新发现课程消失时置 true，不删记录） |
| `Timetable`（新） | `{ config: CourseTableConfig, courses: Vec<Course>, overrides: Vec<CourseOverride>, updated_at: String }` |
| `CourseTableConfig` 新增 `#[serde(default)] pub slots: Option<Vec<TimeSlot>>` | **自定义作息**（2026-09-18 收尾轮追加）：`None`/空 = 用内置校本大节表 `campus_portal::block_time_slots()`；有值 = 用户编辑过的作息，视为唯一事实源。`TimeSlot.alias` 可作大节别名 |

`CourseSource::{Import, Manual}`、`CourseOverride`、`OverrideKind` **沿用现有定义，不改字段**。

### 2.2 存储

- 位置：`%APPDATA%/campushub/timetable.json`（**非凭据，明文**，与 `profile.json` 同级）
- 模块：`tauri-app/src-tauri/src/infra/timetable.rs`（读写 + 原子性由调用方保证；单文件、无数据库）
- TGT 持久化：`session.json` 的 `SessionRecord` 新增 `tgt_b64: Option<String>`（**DPAPI 密文**，
  与 cookie 同级敏感；日志/报告一律不得出现明文 TGT）

### 2.3 IPC 命令（新增 9 条，命名冻结，前端只经 `invokeCommand` 调用）

| 命令 | 入参 | 出参 | 说明 |
|---|---|---|---|
| `get_timetable` | 无 | `TimetableView` | 本地读取；无文件 → 空课表（`courses: []`，不报错） |
| `import_timetable` | 无 | `ImportResult` | 需登录；SSO → 拉取 → diff → 落库 → 返回变更摘要 |
| `add_course_manual` | `ManualCourseInput` | `Course` | `source=Manual`，`colorIndex` 由入参指定 |
| `update_course` | `Course` | `Course` | 用户手工编辑（任意来源；自动更新仍只覆盖 Import） |
| `delete_course` | `id: String` | `()` | 删除 |
| `parse_notice` | `text: String` | `Vec<NoticeCandidate>` | L1/L2 解析，**不入库** |
| `apply_override` | `candidate: NoticeCandidate` | `CourseOverride` | 采纳（高置信自动应用也走这条，`autoApplied` 区分） |
| `revoke_notice` | `noticeId: String` | `u32` | 删除该通知产生的全部 override，返回删除条数 |
| `export_ics` | 无 | `String` | **写入用户下载目录（`课表.ics`，已存在覆盖）并返回写入的完整路径**。2026-09-18 真机验收发现 WebView2 不处理下载（`DownloadStarting` 未接管），前端 Blob 交付不可用，改由后端落盘 |
| `save_time_slots` | `slots: Option<Vec<TimeSlot>>` | `TimetableView` | **2026-09-18 收尾轮追加**：保存自定义作息；传 `null` = 恢复内置校本默认（写回 `config.slots = None`）。返回刷新后的视图，前端免二次拉取 |

`ImportResult`：`{ added: u32, changed: u32, removed: u32, total: u32, changes: Vec<String> }`
（`changes` 为人类可读条目，如 `信息安全 教室 D4-207 → D4-305`）

`ManualCourseInput`：`{ name, teacher, position, day, startSection, endSection, weeks, colorIndex, remark? }`

`TimetableView`（**2026-09-18 批次 4 前修订**）：`{ timetable: Timetable, slots: Vec<TimeSlot>, currentWeek: Option<u32>, today: String }`
——`slots` 取校本大节作息（`campus_portal::block_time_slots()`，唯一事实源，前端不得自行硬编码时间），
`currentWeek` 由 `config.semester_start_date` + 本机今天推（`weeks::current_week`），`today` 为 `YYYY-MM-DD`。

**`slots` 取值口径（2026-09-18 收尾轮修订）**：`config.slots` 有值 → 用它；为 `None`/空 → 回落到内置
`campus_portal::block_time_slots()`。**网格行、ICS 展开、`ceil(小节/2)` 映射三者必须都用同一个 `slots`**，
不得一处分发一处硬编码。自定义作息的行数不固定（用户可增删大节），前端按 `slots.len()` 渲染行。

`NoticeCandidate`：`{ noticeId, courseId?, courseName, changeType, weeks, newDay?, newStartSection?,
newEndSection?, newPosition?, confidence: "high"|"low", reason: String, excerpt: String }`

**命令返回一律套既有 `CommandResult{success, message?, data?}`**（`invokeCommand` 唯一出口已就位）。

### 2.4 自动更新的 diff 语义（冻结）

- 匹配键 = **课程名 + `class_id`（教务 `jxb_id`）**；`class_id` 缺失时退化为仅课程名匹配
- 新出现 → 新增（`source=Import`）；消失 → **置 `disabled=true`**，不删除；字段变化 → 只更新 `Import` 课程
- **`source=Manual` 的课程永不参与 diff，永不被打上 `disabled`**
- 本地手工编辑过的 `Import` 课程字段会被下一次导入覆盖（预期语义，不是 bug）

### 2.5 调课通知 L1/L2（冻结语义）

- 输入：通知正文 + 本地课程表；输出 `Vec<NoticeCandidate>`
- L1 规则层提取：课程名、周次（`第3周` / `3-4周` / `本周`）、星期（`周一`…`周日`）、
  节次（`3-4节` / `第3节`）、教室（`D4-207` 形态 / `教室：` 后）、关键词类型（调课/停课/补课）
- L2 置信：课程名**精确匹配**且周次、星期、节次齐全 → `high`（自动应用）；
  缺任一要素、或课程名匹配到多门 → `low`（进「待确认」列表，用户一键采纳）
- `noticeId`：本轮手动粘贴场景由实现方生成稳定 id（建议 `manual:<内容 sha256 前 16 位>`）；
  M5 接公告流时改用公告 id
- override 叠加于导入课程之上（原数据保留）；`revoke_notice` 按 `noticeId` 整批撤销

### 2.5.1 停课的渲染口径（2026-09-18 收尾轮定，原先未定义）

`OverrideKind::Cancelled` 的语义按 `new_day` 是否为空分两档：

| `new_day` | 语义 | 渲染 |
|---|---|---|
| `Some(d)` | 只停「该周 · 星期 d」那一次课 | 该周星期 d 的原时段显示虚线「已停」占位；本周其他星期的同课不受影响 |
| `None` | 通知没说停哪一天 → **该课程在 `weeks` 列出的周次内整周全停** | 该周内该课**所有**原时段都显示虚线「已停」占位 |

解析侧（`notice.rs`）保持既有行为：通知里提到星期就填进 `new_day`，没提就留 `None`。
`new_start_section`/`new_end_section`/`new_position` 对停课无意义（保留原值或 `None` 均可，渲染层忽略）。

## 4. 铁律

1. 明文密码/TGT/cookie 不进代码、日志、commit、派单 prompt；凭据只经 `CAMPUS_HUB_CREDS` 读
2. 抓到的原始响应（含 PII）只写 `%TEMP%/`，不进仓库
3. 不动 `campus-schedule::default_time_slots()`（golden 钉住）；校本作息走大节表
4. 不改 §2 契约（要改先停下问）
5. 逻辑单元提交一次，`git add` 明确路径（根目录有未跟踪的 `一键填分4.user.js`，不得加入）
6. 每批收尾跑 `cargo test --workspace` + `tsc --noEmit`，并把触达的 CodeWiki 文章更新（`cw index` + `cw meta update`）
